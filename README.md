# COMPAS Fairness Metrics Table 12 Replication

Replicating Table 12 (ICL Sampling Strategies: F, U, E, C) on the COMPAS Dataset using Groq API and Llama 3.3 70B.

## How to Run
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Launch app: `streamlit run app.py`
4. Enter your Groq API Key in the sidebar.
